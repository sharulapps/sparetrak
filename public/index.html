How to use SpareTrack
Part Lifespan
Days between OUTs of the same part on the same machine = how long the part lasts. Next change = last OUT + that many days. Use / year = quantity taken ÷ time between the first and last OUT. Returns are subtracted; OUTs on the same day count once. Needs at least 2 OUTs.
PM Schedule
Change a part before it usually fails: PM date = last change on that machine + the chosen % of how long it usually lasts. Only parts with 3+ changes and a steady life are scheduled.
Spare Part Budget
Next 12 months, from how many of each part you actually use (OUT history, returns subtracted) × its Unit Cost. Parts used for 3+ months: rate from first to last OUT; newer ones: what was used in the last 12 months.
Stock Valuation
Value of the stock on the shelf today = stock × Unit Cost. Dead stock = not taken OUT for the chosen period. Over max = stock above Max Stock.
